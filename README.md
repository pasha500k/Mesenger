# Lynxoria

Lynxoria — современная платформа для защищённых чатов, звонков и совместной работы с векторной доской. Решение рассчитано
на команды, учебные группы и сообщества, которым нужна надёжная переписка и возможность подключать звонки по требованию.

## Ключевые возможности

- 🔐 **Система аккаунтов** — регистрация и вход с хранением пользователей в SQLite, пароли шифруются через bcrypt.
- 🧑‍💼 **Встроенный администратор** — пользователь `admin` с паролем `Hehetoto123` доступен сразу; в панели он может подключаться
  к любому звонку в скрытом режиме и наблюдать за диалогами, оставаясь невидимым для остальных.
- 💬 **Постоянные приватные чаты** между пользователями с поиском по логину, историей сообщений и отправкой файлов.
- 🔊 **Голосовые сообщения** и встраиваемое воспроизведение аудио прямо в браузере.
- 🎥 **Видеозвонки и аудио** через WebRTC: управление микрофоном/камерой, доска появляется только во время звонка.
- 🖊️ **Векторная доска** с инструментами (фигуры, выделение, ластик, перемещение, масштабирование колесиком и кнопками).
- 🗂️ **Обмен файлами** с предпросмотром изображений, видео, PDF и аудио без внешних сервисов.
- 💻 **Electron-оболочка** для сборки Windows-.exe клиента.
- 🌐 **Готовность к продакшену** — настраиваемые CORS, JWT-куки, понятные инструкции по деплою на VDS.

## Структура проекта

```
Mesenger/
├── client/   # Интерфейс на React + Vite + Tailwind CSS
├── server/   # API и WebSocket сервер на Express + Socket.IO + SQLite
└── desktop/  # Electron-оболочка для настольного приложения
```

## Быстрый старт в разработке

```bash
# Установка зависимостей
cd server && npm install
cd ../client && npm install

# Запуск окружения разработки
cd ../server && npm run dev        # API и Socket.IO на http://localhost:4000
cd ../client && npm run dev        # Веб-клиент на http://localhost:5173 (порт авто-подбирается)
```

## Учётная запись администратора

- Логин: `admin`
- Пароль: `Hehetoto123`
- Администратор может открыть `/admin`, увидеть активные звонки, последние регистрации и подключиться к любому чату в режиме
  скрытого наблюдателя. Во время такого подключения пользователи не видят администратора в списке участников, не получают его
  видео и не слышат его микрофон, но администратор слышит и видит остальных.

## Деплой на VDS

1. **Подготовьте окружение**
   ```bash
   sudo apt update
   sudo apt install -y curl git build-essential
   curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
   sudo apt install -y nodejs
   ```
2. **Склонируйте репозиторий и соберите проект**
   ```bash
   git clone <ваш-репозиторий> lynxoria
   cd lynxoria/server && npm install --production && npm run start
   ```
   Сервер запустится на `PORT=4000` (можно переопределить через переменные окружения).
3. **Соберите фронтенд**
   ```bash
   cd ../client
   npm install
   npm run build
   npm run preview -- --host 0.0.0.0 --port 4173
   ```
   Для продакшена обычно отдают содержимое `client/dist` через Nginx или Caddy. Пример конфигурации Nginx приведён в разделе
   `client/README.md`.
4. **Настройте переменные окружения**
   - `PORT` — порт API (по умолчанию `4000`).
   - `CLIENT_ORIGIN` — домен фронтенда (можно указать несколько адресов через запятую, например `https://lynxoria.app`).
   - `JWT_SECRET` — собственный секрет подписи токенов.

## Настольное приложение (.exe)

```bash
cd client
npm run build

cd ../desktop
npm install
npm run package
```

Готовый инсталлятор появится в `desktop/release`. Приложение использует локальный API (`http://localhost:4000`), поэтому сервер
необходимо запустить отдельно.

## Доступное доменное имя

Название *Lynxoria* уникально — популярные зоны вроде `lynxoria.com` и `lynxoria.app` обычно свободны к регистрации (перед
покупкой проверьте у своего регистратора).

## Безопасность и хранение данных

- Все пользователи хранятся в `server/data/app.db` (SQLite).
- Пароли сохраняются в виде bcrypt-хэшей.
- Аутентификация строится на JWT в `httpOnly`-cookie, Socket.IO повторно использует тот же токен.
- Администратор видит только техническую информацию, сообщения остаются в чате и отдаются по отдельным запросам.
