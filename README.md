# NovaCollab

Современная платформа для видеовстреч, совместной работы и обмена файлами.

## Возможности

- 🔐 Система аккаунтов с регистрацией, входом и хранением пользователей в SQLite.
- 🎥 Видеозвонки и аудиосвязь через WebRTC с координацией через Socket.IO.
- 💬 Постоянные приватные чаты между пользователями с поиском по логину и историей сообщений на дашборде.
- 🔊 Голосовые сообщения прямо из браузера без сторонних приложений.
- 🧑‍🤝‍🧑 Список участников активного чата и управление сеансами.
- 🖊️ Векторная доска, которая доступна только во время активного звонка и по запросу участников.
- 📁 Обмен файлами (и видео) непосредственно в чате без сторонних сервисов.
- 🎨 Современный интерфейс с акцентом на темную тему и плавные градиенты.

## Структура проекта

```
Mesenger/
├── client/   # Интерфейс на React + Vite + Tailwind CSS
└── server/   # API и WebSocket сервер на Express + Socket.IO + SQLite
```

## Требования

- Node.js 18+
- npm 9+

## Быстрый старт

### 1. Установка зависимостей

```bash
cd server
npm install
cd ../client
npm install
```

### 2. Запуск серверов разработки

В одном терминале:

```bash
cd server
npm run dev
```

В другом терминале:

```bash
cd client
npm run dev
```

После этого интерфейс будет доступен по адресу <http://localhost:5173>, а API — на <http://localhost:4000>.

### 3. Настольное приложение (.exe)

Чтобы собрать десктопную версию для Windows:

```bash
# подготовьте фронтенд
cd client
npm run build

# соберите electron-оболочку
cd ../desktop
npm install
npm run package
```

Готовый установщик появится в `desktop/release`. Приложение использует локальный API (`http://localhost:4000`), поэтому сервер необходимо запустить отдельно.

## Переменные окружения

- `PORT` — порт HTTP сервера (по умолчанию `4000`).
- `CLIENT_ORIGIN` — адрес (или несколько адресов через запятую) фронтенда для настройки CORS. По умолчанию используются стандартные dev-URL Vite: `http://localhost:5173`, `http://localhost:5174`, а также их варианты с `127.0.0.1`.
- `JWT_SECRET` — секрет для подписи JWT (по умолчанию используется значение для разработки).

## Сборка и запуск в production

```bash
cd server
npm install --production
npm run start
```

```bash
cd client
npm install
npm run build
npm run preview
```

Готовая сборка фронтенда будет находиться в `client/dist`.

## Безопасность и хранение данных

- Данные пользователей хранятся в файле SQLite `server/data/app.db`.
- Пароли сохраняются в виде bcrypt-хэшей.
- Аутентификация осуществляется при помощи JWT, передаваемых в `httpOnly`-cookie.
